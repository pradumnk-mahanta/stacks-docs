## [0.0.4] - 2026-11-01
* Initial release of Stacks to Playstore.
* Unified Connected Services Dashboard: Add and switch between multiple self-hosted server instances with live connection status dots.
* Komodo Integration: Connect via local username/password (with TOTP support) or API Key & Secret.
* Servers & Stacks Overview: Real-time CPU, RAM, and Storage stats; visual container count pills (`running | stopped`).
* Container Lifecycle Management: One-tap Start, Stop, and Restart actions for containers.
* Interactive Terminal Console: Full PTY-backed terminal with `sh`, `bash`, or `attach` shell selection.
* Real-Time Streaming Logs: Streamable, refreshable container log viewer with line count and timestamp controls.
* Updated Release Workflow
* Added Create Stack Options
* Added Portainer Support
* Added Docker API Support
* Added SSH Support
